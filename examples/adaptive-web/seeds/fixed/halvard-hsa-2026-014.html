HSA-2026-014: Critical vulnerability in Halvard Gateway web portal

Advisory IDHSA-2026-014
CVECVE-2026-41877
SeverityCritical
CVSS 3.19.8 (AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H)
First published22 September 2026
Last updated27 September 2026 (revision 3)
WorkaroundYes

Summary

A flaw in how the web portal of Halvard Gateway firmware parses session cookies lets an unauthenticated attacker run commands as root on the appliance. An attacker needs only network access to the web portal.

Halvard is aware of reports that this vulnerability is being exploited. We strongly recommend that customers upgrade now.

Affected products

ProductAffected firmwareFixed firmware
HG-2007.0.0 to 7.2.37.2.4
HG-4007.0.0 to 7.2.37.2.4
HG-9007.0.0 to 7.2.37.2.4

Firmware 6.x is not affected. Halvard Cloud Edge is not affected.

Workaround

Until you can upgrade, turn off the web portal on the WAN interface: System › Administration › Web portal › Interfaces, clear WAN, then Apply. Management from the LAN still works. This blocks the attack from the internet. It does not fix the flaw.

Solution

Upgrade to firmware 7.2.4, available from the download centre since 22 September 2026. See KB-3381: Upgrading Halvard Gateway firmware.

Indicators of compromise

Look in /var/log/portal/access.log for requests to /portal/session/refresh with an unusually long HGSESSID cookie. See KB-3384 for a check script.
